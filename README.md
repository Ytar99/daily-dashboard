# Daily Dashboard

Проект представляет собой интерактивную dashboard-панель с виджетами, поддерживающую несколько цветовых тем и возможность кастомизации.

## 📋 Требования

- **Минимальная версия Node.js**: 18.12
- **Рекомендуемая версия Node.js**: 20.x или выше

## 🛠️ Установка и запуск

1. Установите зависимости:

```bash
npm install
```

2. Запустите сервер разработки:

```bash
npm run dev
```

3. Для production-сборки:

```bash
npm run build
```

## 📁 Структура проекта

```
index.html              # HTML-шаблон
src/
├── styles/
│   ├── 01_root.css      # CSS-переменные и темы
│   ├── 02_global.css    # Глобальные стили
│   ├── 03_dashboard.css # Стили dashboard
│   ├── 04_widgets.css   # Стили виджетов
│   └── widgets/
│       └── clock.css    # Стили виджета часов
├── dashboard.js         # Основной класс dashboard
├── widget.js           # Базовый класс виджета
├── widget-manager.js   # Менеджер виджетов
├── widgets/
│   └── clock.js        # Виджет часов
└── main.js             # Точка входа
```

## 🔧 Разработка виджетов

Для создания нового виджета:

1. Создайте класс, наследуемый от `Widget`
2. Реализуйте методы `render()`, `init()`, и при необходимости `destroy()`
3. Зарегистрируйте виджет в `WidgetManager`

## 📦 Зависимости

- **Vite** - сборщик проекта
- **Interact.js** - для drag-and-drop функциональности
