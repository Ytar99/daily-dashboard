# Основы разработки проекта

## Структура проекта

```
daily-dashboard/
└── src/
    ├── core/
    │   ├── dashboard.js       # Логика доски
    │   ├── storage.js         # Работа с localStorage
    │   └── drag-n-drop.js     # Система перетаскивания
    ├── widgets/
    │   ├── widget.js          # Базовый класс виджета
    │   ├── todo.js
    │   ├── clock.js
    │   ├── timer.js
    │   └── ...                # Остальные виджеты
    ├── app.js                 # Инициализация приложения
    └── styles/
        ├── main.css           # Общие стили
        └── widgets/           # Стили виджетов
            ├── todo.css
            └── ...
```

## Принципы разработки

1. **Модульность**:

   - Каждый виджет - самостоятельный модуль
   - Минимальная зависимость между модулями
   - Пример структуры виджета:

     ```javascript
     // src/widgets/Clock.js
     export class ClockWidget {
       constructor(config) {
         // Инициализация
       }

       render() {
         // Возвращает DOM-элемент
       }

       destroy() {
         // Очистка ресурсов
       }

       ...
     }
     ```

2. **Состояние приложения**:
   - Сохраняем layout виджетов в localStorage
   - Каждый виджет управляет своим внутренним состоянием

## Рабочий процесс

1. Для новой задачи создайте ветку от `main`
2. Начните с проектирования интерфейса виджета

## Стиль кода

1. Именование:

   - Классы: `PascalCase`
   - Переменные: `camelCase`
   - Константы: `UPPER_CASE`

2. Форматирование:

   - Отступ: 2 пробела
   - Фигурные скобки: всегда
   - Точка с запятой: обязательна

3. Комментарии:
   - Описывайте сложную логику
   - Избегайте комментариев вроде описания "что это такое", вместо этого пишите "почему это так"
   - Используйте JSDoc для сложных функций (опционально)

## Тестирование

- Проверяйте все состояния виджета
- Тестируйте на разных размерах экрана
