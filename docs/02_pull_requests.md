# Работа с Pull Requests (PR)

## Процесс работы

1. Завершите работу в своей ветке:

   ```bash
   git add .
   git commit -m "Завершение задачи"
   git push
   ```

2. Перейдите на GitHub репозитория:
   https://github.com/Ytar99/daily-dashboard

3. Создайте Pull Request:

   - Нажмите "Pull requests" → "New pull request"
   - Выберите: base: `main`, compare: `ваша-ветка`
   - Нажмите "Create pull request"

4. Заполните информацию:
   - **Title**: Краткое описание изменений
   - **Description**:
     - Что сделано и зачем
     - Скриншоты (если уместно)

## Процесс ревью

1. Назначьте ревьюверов (в правой колонке):

   - Основной: @Ytar99

2. Обсуждение кода:

   - Ревьюверы оставляют комментарии
   - Отвечайте на комментарии прямо в интерфейсе GitHub
   - Для изменений: просто добавьте новые коммиты в ветку

3. Исправление замечаний:
   - Внесите правки в своей ветке
   - Сделайте коммит и отправьте изменения
   ```bash
   git add .
   git commit -m "Исправление замечаний ревью"
   git push
   ```
   - PR обновится автоматически

## После ревью

1. Получите approval (✔️) от ревьювера
2. Нажмите "Merge pull request"
3. Удалите ветку (кнопка появится после мержа)

## Правила хорошего PR

1. Один PR = одна логическая задача/фича
2. Размер PR должен позволять сделать ревью за 15-30 минут
3. Включайте только релевантные изменения
4. Описывайте контекст - почему изменения необходимы
