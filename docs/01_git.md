# Основы работы с Git

## Начальная настройка

1. Установите Git: https://git-scm.com/downloads
2. Настройте имя и email (выполнить в терминале):

   ```bash
   git config --global user.name "Ваше Имя"
   git config --global user.email "ваша@почта.com"
   ```

3. Проверьте настройки:
   ```bash
   git config --list
   ```

## Работа с репозиторием

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/Ytar99/daily-dashboard.git
   cd daily-dashboard
   ```

2. Перед началом работы всегда обновляйте локальную копию:

   ```bash
   git pull origin main
   ```

3. Создайте новую ветку для задачи:

   ```bash
   git switch -c feature/краткое-описание-задачи
   ```

   Пример: `git switch -c feature/add-clock-widget`

   _Флаг -c указывает на то, что ветку нужно создать - create_

## Работа с изменениями

**‼️Основные действия будут делаться через интерфейс VS Code (или другого редактора), команды даны для справки ‼️**

1. Проверьте статус изменений:

   ```bash
   git status
   ```

2. Добавьте файлы в отслеживание:

   ```bash
   git add имя_файла      # Добавить конкретный файл
   git add .              # Добавить все измененные файлы
   ```

3. Сделайте коммит:

   ```bash
   git commit -m "Краткое описание изменений"
   ```

   Пример: `git commit -m "Добавлен виджет часов"`

4. Отправьте изменения на сервер:
   ```bash
   git push -u origin имя-вашей-ветки
   ```

## Полезные команды

- Просмотр истории коммитов: `git log`
- Просмотр изменений: `git diff`
- Отмена изменений в файле: `git restore имя_файла`
- Переключение между ветками: `git switch имя-ветки`

## Важные правила

1. Никогда не работайте напрямую в ветке `main`
2. Делайте частые мелкие коммиты вместо одного большого
3. Пишите понятные сообщения коммитов на английском
